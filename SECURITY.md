# Security policy

## Supported version

Milkbox is a continuously deployed web application. The current `main` branch
and the revision published at <https://milkbox.stuntcamp.app> are supported.
Older revisions and locally modified builds are not maintained.

## Reporting a vulnerability

Please use [GitHub private vulnerability reporting][report] rather than opening
a public issue. Include reproduction steps, affected browsers or platforms,
the expected impact, and any suggested mitigation.

You should receive an acknowledgement within seven days. Please allow time to
investigate and deploy a fix before publishing details.

Do not include access tokens, OneDrive content, account details, or other
personal data in a report.

[report]: https://github.com/kypflug/milkbox/security/advisories/new
